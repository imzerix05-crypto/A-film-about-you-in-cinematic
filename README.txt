A FILM ABOUT YOU — CINEMATIC BIRTHDAY SITE

This is a multi-screen, Netflix-inspired birthday film for Ethan, made with love by Hazel.
It has separate full-screen scenes (not one long scrolling page), animated transitions, a 12-photo carousel, a soundtrack player using the newly trimmed song, three letter pages, paginated reasons, a finale, and next/previous controls. Swipe left/right on mobile to change scenes.

IMPORTANT: Keep all filenames and folders exactly as provided. The song filename contains spaces and must remain exactly:
assets/audio/RANG JO LAGYO RE TRIMMED.mp3

For GitHub Pages on mobile:
1. Download and extract this ZIP on your phone.
2. Open the extracted A_Film_About_You_CINEMATIC folder.
3. Upload the CONTENTS of that folder to the ROOT of your GitHub repository (index.html, style.css, script.js, content.js, assets folder, README.txt). Do not upload only the ZIP and do not place the files inside another nested folder.
4. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save if the button is enabled.
5. Wait for the latest Actions > pages build and deployment run to finish with a green check.
6. Open the Pages URL shown in Settings > Pages.

Audio playback requires the viewer to tap Play; mobile browsers do not allow reliable autoplay before a user gesture.
